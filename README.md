Junior Astronaut Game

A 2D decision-making astronaut training game for kids.

Become a Cadet and train with Commander Reyes and AI ARIA. Travel from Earth to ISS, Moon, and finally land on Mars.

How to Play
Make real astronaut choices. Every choice changes your meters.
Manage O2, Water, Food, Power, Shield, Fuel, Health, Morale and Science.
Keep Sprout - your lettuce plant - alive!

Levels
Level 1: Earth Training
Level 2: ISS to Moon Journey
Level 3: Mars - Landing to Survival (17 Scenes, 4 Parts)

Features
17+ Interactive Scenes with A/B/C Choices
2 Mini-Games: Mars Landing + Fix The Leak
Mars Journey Map + Checkpoints + Save & Take a Break
Finale Ranking System + 3 Endings: Star / Survivor / Lesson
Mobile Landscape Mode + Laptop 1280x720 Mode

Built With
React + Vite + TypeScript + Tailwind CSS

Run Locally
npm install
npm run dev
